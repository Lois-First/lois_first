# 第 4-6 章：表达式、语句与函数

## 第 4 章 表达式

### 重点

- 表达式有值和类型；运算符的优先级决定分组，结合律决定同级运算方向，但不等于求值顺序。
- 左值指向持久对象，右值通常是临时值。引用绑定规则决定是否能修改对象。
- `&&`、`||`、`?:` 和逗号运算符有明确的短路/顺序行为；其他复杂表达式不要依赖未规定的求值顺序。
- 隐式类型转换包括整型提升、算术转换、数组/函数到指针转换。需要表达意图时使用 `static_cast`。
- `sizeof` 返回 `size_t`；对数组使用时得到整个数组大小，对指针则只得到指针大小。

### C++11 新特性

- 统一列表初始化和 `std::initializer_list` 优先匹配：`std::vector<int> v{1,2};`。
- 右值引用（`T&&`）为移动语义和完美转发提供基础。
- `static_assert(condition, "message")` 在编译期检查不变量。
- `noexcept(expr)` 可查询表达式是否保证不抛异常。

```cpp
#include <type_traits>

template <typename T>
auto twice(T value) -> typename std::decay<T>::type { return value + value; }

static_assert(sizeof(int) >= 2, "int is too small");
```

## 第 5 章 语句

- `if`、`switch`、`while`、`do while`、`for` 控制流；`break` 跳出最近一层，`continue` 进入下一次迭代。
- `switch` 的 case 标签必须是整型常量表达式，忘记 `break` 会故意或意外贯穿。
- `try/catch/throw` 处理异常；异常对象按值抛出、按引用捕获，通常使用 `const` 引用。
- `return` 结束函数；局部对象会按构造逆序析构，RAII 依赖这一点。

**C++11：** 基于范围的 `for`；`try` 块中的变量作用域；`noexcept` 函数异常规范；`std::exception_ptr` 可保存当前异常。

```cpp
for (const auto &item : items) {
    if (item.empty()) continue;
    process(item);
}
```

## 第 6 章 函数

### 重点

- 参数按值、指针或引用传递；只读大对象常用 `const T&`，需要取得所有权时使用值并配合移动。
- 函数声明应放在头文件，定义放在源文件；默认实参只能从右向左提供，且应在同一作用域只声明一次。
- 重载按参数列表区分，不能只靠返回类型区分；`const` 成员函数参与重载。
- `inline` 是对定义位置和 ODR 的请求，不保证真的内联。
- 局部静态变量只初始化一次；递归必须有终止条件。

### C++11 新特性

| 特性 | 用法 |
|---|---|
| 尾置返回类型 | `auto f(int x) -> decltype(x)`，返回类型依赖参数时很方便 |
| `constexpr` 函数 | 函数体受限但可在编译期求值；仍可运行时调用 |
| `= delete` | 禁止特定重载，如 `void f(double) = delete;` |
| `initializer_list` 参数 | `void print(std::initializer_list<int> xs)` |
| 可变参数模板 | `template<class... Args> void log(Args&&... args)` |
| 完美转发 | `std::forward<T>(arg)` 保留实参值类别 |
完美转发，在模板函数中，将arg以原始值的方式传递。
eg:void process(int& x) { std::cout << "处理左值" << std::endl; }
// 包装器模板：完美转发参数给 process
` template<typename T> `
```cpp
void wrapper(T&& arg) {
    // std::forward<T>(arg) 保持 arg 的原始左右值类型
    process(std::forward<T>(arg)); 
}
```

### 标准库小工具

- `<cassert>`：`assert(expr)` 在调试构建中验证前置条件。
- `<cstdlib>`：`std::move` 不在这里；终止程序用 `std::exit`，随机数请用 `<random>`。
- `<utility>`：`std::move`、`std::forward`、`std::swap`、`std::pair`。

```cpp
#include <initializer_list>
#include <numeric>

int sum(std::initializer_list<int> xs) {
    return std::accumulate(xs.begin(), xs.end(), 0);
}
```

### 易错点

- 返回局部对象的引用或指针会悬空；按值返回通常会被移动/省略。
- 默认参数不是函数类型的一部分；函数指针不能“携带”默认值。
- `std::move` 只做类型转换，不执行移动；移动后对象必须仍可析构和赋值。
- 完美转发只在模板参数推导的转发引用中成立。
