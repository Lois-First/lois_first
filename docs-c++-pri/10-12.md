# 第 10-12 章：算法、关联容器与动态内存

## 第 10 章 泛型算法

- 算法通过迭代器适配容器，分为只读、修改、排序、数值和集合算法。
- 半开区间 `[begin, end)` 是统一约定；算法通常不检查迭代器合法性。
- 常用：`find`、`count`、`accumulate`、`copy`、`fill`、`transform`、`sort`、`stable_sort`、`binary_search`、`lower_bound`、`remove`。
- `remove` 只移动元素并返回新逻辑尾，必须配合容器 `erase`：`v.erase(std::remove(...), v.end())`。

### C++11 新特性

- Lambda：`[capture](params) -> ret { body }`，捕获方式 `[=]`、`[&]`、`[x]`、`[this]`。
- `auto` 推导迭代器和 Lambda 返回值。
- `std::begin/end`、`cbegin/cend` 支持数组和容器。
- `std::bind` 绑定参数，`std::placeholders::_1` 表示调用时的位置参数；新代码通常优先 Lambda。
- `std::function<R(Args...)>` 类型擦除任意可调用对象，空对象调用会抛 `bad_function_call`。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v{1, 2, 3, 4};
    int factor = 3;
    std::transform(v.begin(), v.end(), v.begin(),
                   [factor](int x) { return x * factor; });
    v.erase(std::remove_if(v.begin(), v.end(),
                           [](int x) { return x % 2 == 0; }), v.end());
    for (auto x : v) std::cout << x << ' ';
}
```

## 第 11 章 关联容器

| 容器 | 组织方式 | 特点 |
|---|---|---|
| `map` / `set` | 有序树 | 查找、插入 O(log n) |
| `multimap` / `multiset` | 有序且允许重复键 | `equal_range` 得到等价区间 |
| `unordered_map` / `unordered_set` | **C++11** 哈希 | 平均 O(1)，最坏 O(n) |

`map<K,V>` 的 `operator[]` 在键不存在时会插入默认值；只查询使用 `find` 或 `at`。插入结果通常是 `pair<iterator,bool>`。桶接口：`bucket_count`、`load_factor`、`rehash`、`reserve`。自定义键需提供 `operator==` 和哈希函数。

## 第 12 章 动态内存

- `new/delete` 与 `new[]/delete[]` 必须匹配；裸 `new` 容易泄漏和异常不安全。
- `shared_ptr` 共享所有权，引用计数归零时释放；`weak_ptr` 观察但不拥有，可用 `lock()` 获取临时 `shared_ptr`。
- `unique_ptr` 独占所有权，不可拷贝，只能移动；默认删除器也支持数组特化。
- `make_shared`、`make_unique`（后者是 C++14，C++11 需手写）优先于直接 `new`；C++11 可用 `shared_ptr<T>(new T(...))`，但表达式异常安全性较弱。
- `allocator` 为容器等低层组件提供分配与构造接口。

```cpp
#include <memory>

struct Node { int value; explicit Node(int v) : value(v) {} };

std::shared_ptr<Node> make_node(int value) {
    return std::make_shared<Node>(value);
}

void consume(std::unique_ptr<Node> node) { /* 获得所有权 */ }
```

### 易错点

- 从同一个裸指针构造两个 `shared_ptr` 会导致重复释放。
- 循环引用要用 `weak_ptr` 打断。
- `shared_ptr` 的控制块与对象可能分开分配；`make_shared` 通常更高效。
