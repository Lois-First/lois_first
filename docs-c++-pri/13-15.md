# 第 13-15 章：拷贝控制、运算符与面向对象

## 第 13 章 拷贝控制

- 特殊成员函数：析构、拷贝构造、拷贝赋值；C++11 增加移动构造、移动赋值。
- 资源类遵循三/五法则：自定义析构通常意味着需要同时审查拷贝和移动操作。
- 拷贝赋值应处理自赋值并保证异常安全；常见写法是复制并交换。
- 移动操作接管资源，将源对象置于可析构、可赋值的有效状态。
- 返回值优化可能省略拷贝，但代码不能依赖其一定发生。

```cpp
#include <algorithm>
#include <cstddef>

class Buffer {
public:
    explicit Buffer(std::size_t n) : size_(n), data_(new int[n]{}) {}
    ~Buffer() { delete[] data_; }
    Buffer(const Buffer &other) : Buffer(other.size_) {
        std::copy(other.data_, other.data_ + size_, data_);
    }
    Buffer(Buffer &&other) noexcept : size_(other.size_), data_(other.data_) {
        other.size_ = 0; other.data_ = nullptr;
    }
    Buffer &operator=(Buffer other) noexcept { swap(*this, other); return *this; }
    friend void swap(Buffer &a, Buffer &b) noexcept {
        using std::swap; swap(a.size_, b.size_); swap(a.data_, b.data_);
    }
private: std::size_t size_; int *data_;
};
```

## 第 14 章 重载运算与类型转换

- 运算符重载至少一个操作数必须是类或枚举类型；保持与内置运算符相似的语义。
- 成员运算符适合需要修改左操作数的场景；对称二元运算常写非成员函数。
- `operator bool() const` 可提供条件上下文转换；C++11 用 `explicit` 防止参与普通算术转换。
- 函数调用运算符让对象成为“函数对象”；下标、箭头、输入输出运算符有特定惯例。
- 转换构造函数与转换运算符可能造成隐式转换链，通常使用 `explicit` 控制。

## 第 15 章 面向对象程序设计

- 基类通过虚函数提供运行时多态；基类析构函数若要多态删除必须为 `virtual`。
- 派生类对象包含基类子对象；构造顺序为虚基类、基类、成员、派生类主体，析构相反。
- 公有继承表达“是一个”；组合表达“拥有一个”。避免不必要的继承层次。
- `override` 检查确实重写基类虚函数，`final` 禁止继续重写或继承。
- 纯虚函数使类抽象；对象切片发生在按值复制基类对象时。

```cpp
struct Shape { virtual ~Shape() = default; virtual double area() const = 0; };
struct Circle final : Shape {
    explicit Circle(double r) : radius(r) {}
    double area() const override { return 3.141592653589793 * radius * radius; }
private: double radius;
};
```

### 易错点

- 多态基类没有虚析构时，用 `delete Base*` 是未定义行为。
- 构造函数中调用虚函数不会分派到派生类版本。
- 通过引用/指针使用多态，避免按值传参造成切片。
