# 第 1-3 章：基础类型与标准库入门

## 第 1 章 开始

### 重点

- 一个最小程序由 `main` 开始，返回 `int`；返回 0 表示成功，非 0 表示失败。
- 编译过程大致是预处理、编译、汇编、链接。声明告诉编译器“名字是什么”，定义还会分配实体。
- 标准输入输出通过流完成。`std::cin`、`std::cout`、`std::cerr`、`std::clog` 分别用于输入、普通输出、立即错误输出、缓冲日志输出。
- `<<` 与 `>>` 返回左侧流，因此可以连续操作；流放进条件表达式时会检查其状态。
- `while (std::cin >> value)` 是读取未知数量数据的标准写法：成功则继续，EOF 或格式错误则停止。

### 标准库速查

| 名称 | 是什么 | 怎么用 |
|---|---|---|
| `<iostream>` | 标准流头文件 | `#include <iostream>` |
| `std::cin` | 标准输入流 | `std::cin >> n` |
| `std::cout` | 标准输出流 | `std::cout << n` |
| `std::cerr` | 通常不缓冲的诊断流 | `std::cerr << "error\n"` |
| `std::clog` | 通常缓冲的诊断流 | `std::clog << "trace\n"` |
| `std::endl` | 输出换行并刷新缓冲区 | 交互提示后使用；普通换行优先 `\n` |

```cpp
#include <iostream>

int main() {
    int sum = 0, value = 0;
    while (std::cin >> value)
        sum += value;
    std::cout << sum << '\n';
    return 0;
}
```

### 易错点

- 忘记命名空间限定 `std::`；头文件中不要写 `using namespace std;`。
- `endl` 不只是换行，还会刷新，循环中滥用可能明显降低性能。
- 读取失败后流会保持失败状态，必须 `clear()` 后才能继续读。

## 第 2 章 变量和基本类型

### 重点

- 算术类型包括整型（含字符、布尔）与浮点型。精确宽度取决于实现；需要固定宽度时用 `<cstdint>` 的 `int32_t` 等。
- 无符号运算按模数回绕；有符号溢出是未定义行为。不要在表达式里随意混用有符号和无符号数。
- 引用是对象的别名，定义时必须绑定；指针是对象，能改变指向，也能为空。
- `const` 对象不能被普通引用/指针修改；底层 `const` 描述所指对象，顶层 `const` 描述指针本身。
- 声明由基本类型和声明符组成。复杂声明从变量名向外读；工程代码应借助类型别名拆开。
- 作用域决定名字可见区域，生命周期决定对象何时存在，两者不可混淆。

### C++11 新特性

| 特性 | 含义与用途 | 示例 |
|---|---|---|
| 列表初始化 | 统一 `{}` 语法，禁止丢失信息的窄化 | `int n{42}; vector<int> v{1,2};` |
| `nullptr` | 专用空指针值，可转换到任意指针类型 | `int *p = nullptr;` |
| `constexpr` | 声明编译期常量；其初始值必须是常量表达式 | `constexpr int size = 16;` |
| `auto` | 由初始化器推导类型；通常丢弃顶层 `const` 和引用 | `auto n = 42;` |
| `decltype` | 推导表达式类型但不求值；规则对括号敏感 | `decltype(x) y = x;` |
| `using` 别名 | 现代类型别名语法 | `using Count = unsigned long;` |

```cpp
#include <cstddef>

constexpr std::size_t square(std::size_t n) { return n * n; }

int main() {
    constexpr auto area = square(4); // 编译期得到 16
    const int value = 7;
    auto copy = value;               // int，顶层 const 被忽略
    const auto &alias = value;       // const int&
    decltype(value) exact = 8;       // const int
    (void)area; (void)copy; (void)alias; (void)exact;
}
```

### `decltype` 快速规则

- `decltype(name)`：得到该实体声明的类型。
- `decltype((name))`：括号表达式是左值，通常得到 `T&`。
- 表达式结果是左值得到 `T&`，将亡值得到 `T&&`，纯右值得到 `T`。

### 易错点

- 未初始化的局部内置类型值不确定，读取它是未定义行为。
- `const int *p` 是“指向常量的指针”；`int *const p` 是“常量指针”。
- `auto list = {1, 2}` 推导为 `std::initializer_list<int>`，不是数组或 `vector`。
- `constexpr` 指针的 `constexpr` 修饰的是指针本身（顶层 const），不是所指对象。

## 第 3 章 字符串、向量和数组

### `std::string`

`string` 是可变长字符序列，负责自己的内存，通常优先于 C 风格字符数组。

| 操作 | 说明 |
|---|---|
| `string s;` | 空字符串 |
| `string s(n, ch);` | 构造 n 个字符 |
| `s.empty()` / `s.size()` | 判空 / 字符数，`size()` 返回无符号 `size_type` |
| `s[i]` / `s.at(i)` | 不检查边界 / 检查边界并可能抛异常 |
| `s1 + s2` | 拼接；至少一侧需要是 `string` 才能串起字面量 |
| `s.substr(pos, n)` | 取得子串 |
| `s.find(x)` | 查找，失败返回 `string::npos` |
| `getline(in, s)` | 读取一整行并丢弃换行符 |

`<cctype>` 常用函数：`isalnum`、`isalpha`、`isdigit`、`isspace`、`islower`、`isupper`、`tolower`、`toupper`。传参应先转成 `unsigned char`，否则负的 `char` 可能触发未定义行为。

### `std::vector`

`vector<T>` 是连续存储、自动扩容的同类型元素序列，是默认首选的动态序列容器。

| 操作 | 说明 |
|---|---|
| `vector<T> v;` | 空向量 |
| `vector<T> v(n)` | n 个值初始化元素 |
| `vector<T> v(n, x)` | n 个值为 x 的元素 |
| `v.push_back(x)` | 尾部追加元素 |
| `v.empty()` / `v.size()` | 判空 / 元素数 |
| `v[i]` / `v.at(i)` | 不检查 / 检查下标访问 |
| `v.begin()` / `v.end()` | 首元素 / 尾后迭代器 |
| `v.cbegin()` / `v.cend()` | **C++11** 只读迭代器 |

### C++11 新特性

- 范围 `for`：`for (auto &x : values) x *= 2;`。要修改元素必须使用引用。
- 通用 `begin/end`：`std::begin(array)` 与 `std::end(array)` 也能处理内置数组。
- `vector` 列表初始化：`std::vector<int> v{1, 2, 3};`。
- `cbegin/cend`：无论容器本身是否为常量，都取得常量迭代器。

```cpp
#include <algorithm>
#include <cctype>
#include <iostream>
#include <string>
#include <vector>

std::string normalized(std::string text) {
    for (char &ch : text) {
        unsigned char uch = static_cast<unsigned char>(ch);
        ch = static_cast<char>(std::tolower(uch));
    }
    return text;
}

int main() {
    std::vector<int> values{4, 1, 3};
    std::sort(values.begin(), values.end());
    for (const auto value : values)
        std::cout << value << ' ';
    std::cout << normalized("Cpp") << '\n';
}
```

### 数组、指针和迭代器

- 内置数组大小固定且必须是常量表达式；不能直接拷贝或赋值。
- 数组在多数表达式中转换为首元素指针，但 `decltype`、取地址、`sizeof` 等场景例外。
- 指针区间使用半开形式 `[begin, end)`；尾后指针只能比较，不能解引用。
- 多维数组本质是“数组的数组”。范围遍历除最内层外应使用引用，避免子数组退化成指针。

### 易错点

- 对空 `string/vector` 使用下标，或用 `<= end()` 解引用尾后迭代器。
- `size()` 返回无符号数，`size() - 1` 在空容器上会下溢。
- 在范围 `for` 中改变 `vector` 的容量（如 `push_back`）会使当前迭代器失效。
- C 字符串必须以空字符结尾；比较内容用 `strcmp`，不能比较指针。新代码优先 `string`。
