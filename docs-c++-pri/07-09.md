# 第 7-9 章：类、IO 与顺序容器

## 第 7 章 类

- 类由数据成员、成员函数、访问控制组成；`public` 是接口，`private` 保持不变量。
- 构造函数用初始化列表初始化成员，成员初始化顺序由声明顺序决定，不由列表书写顺序决定。
- `this` 指向当前对象；`const` 成员函数不能修改普通成员。
- `static` 数据成员属于类而非对象；友元获得访问权限但不是成员。
- 聚合类可用列表初始化；封装类应提供稳定接口而非暴露表示。

### C++11 新特性

- 类内成员初始值：`int count = 0;`，构造函数未显式初始化时使用它。
- 委托构造：`Widget() : Widget(0) {}`。
- `= default` 请求编译器生成默认构造/拷贝/移动操作；`= delete` 禁用它们。
- `using Base::Base` 继承基类构造函数。
- 非静态数据成员可使用花括号或等号初始化。

```cpp
class Counter {
public:
    Counter() = default;
    explicit Counter(int initial) : value_(initial) {}
    void increment() { ++value_; }
    int value() const { return value_; }
private:
    int value_ = 0;
};
```

## 第 8 章 IO 库

- `istream`/`ostream` 是格式化 IO；`fstream` 负责文件，`stringstream` 负责内存字符串。
- 文件模式：`in`、`out`、`app`、`ate`、`trunc`、`binary`；打开失败检查 `is_open()` 或流状态。
- `getline` 读取整行；格式化读取后若要换行，先处理残留换行符。
- 状态位：`goodbit`、`eofbit`、`failbit`、`badbit`；`clear()` 清状态，`ignore()` 丢弃输入。
- 操纵符 `<iomanip>`：`std::setw`、`std::setprecision`、`std::fixed`、`std::boolalpha`。

```cpp
#include <fstream>
#include <stdexcept>
#include <string>

std::string first_line(const std::string &path) {
    std::ifstream in(path);
    if (!in) throw std::runtime_error("cannot open file");
    std::string line;
    std::getline(in, line);
    return line;
}
```

## 第 9 章 顺序容器

| 容器 | 特点 | 典型选择 |
|---|---|---|
| `vector` | 连续内存，随机访问快，尾插快 | 默认序列容器 |
| `deque` | 两端插入快，随机访问 | 需要两端操作 |
| `list` | 双向链表，任意位置插入稳定 | 频繁中间插入且已有迭代器 |
| `forward_list` | **C++11** 单向链表，内存小 | 只需单向遍历 |
| `array` | **C++11** 固定大小、值语义 | 替代内置数组 |
| `string` | 字符序列 | 文本 |

常用成员：`front/back`、`push_front/push_back`、`emplace_front/emplace_back`、`insert`、`erase`、`clear`、`resize`、`capacity`、`reserve`。修改 `vector` 可能令迭代器/引用失效：扩容后全部失效，未扩容时插入点之后失效。

```cpp
#include <array>
#include <vector>

std::array<int, 3> a{{1, 2, 3}}; // C++11 某些编译器需双花括号
std::vector<int> v;
v.reserve(100);
v.emplace_back(42);              // 直接在容器中构造
```

### 易错点

- `reserve` 改容量不改元素数；`resize` 改元素数。
- `list` 没有随机访问，不适合 `it + n`。
- `forward_list` 没有 `size()`，插入/删除使用 `before_begin` 和 `insert_after`。
