# 第 16-19 章：模板、工具与特殊库

## 第 16 章 模板与泛型编程

- 函数模板和类模板在实例化时生成具体代码；模板参数可为类型、非类型或模板本身。
- 名字查找分为定义时和实例化时；依赖名需要 `typename`，依赖模板需要 `template` 消歧。
- 特化、偏特化用于为特定类型提供不同实现；SFINAE 可在替换失败时丢弃候选。
- 类型特征 `<type_traits>`：`is_same`、`is_integral`、`remove_reference`、`decay`、`enable_if`。
- 参数包展开支持通用转发和元编程。

```cpp
#include <utility>

template <typename F, typename... Args>
decltype(auto) invoke(F &&f, Args&&... args) {
    return std::forward<F>(f)(std::forward<Args>(args)...);
}
```

## 第 17 章 标准库特殊设施

| 组件 | 主要类型/函数 | 用途 |
|---|---|---|
| `tuple` | `std::tuple`, `make_tuple`, `get<I>` | 异构定长值集合 |
| `bitset` | `set`, `reset`, `flip`, `test`, `count`, `to_ulong` | 固定二进制位 |
| 正则 | `regex`, `regex_match`, `regex_search`, `regex_replace`, `smatch` | 模式匹配 |
| 随机数 | 引擎 `mt19937`；分布 `uniform_int_distribution` | 可复现、可组合随机数 |
| 时间 | `chrono::duration`, `time_point`, `steady_clock` | 计时与时间间隔 |
| 数值限制 | `numeric_limits<T>::max/min/is_signed` | 查询类型属性 |
| 错误码 | `error_code`, `system_error` | 传递系统错误 |

### C++11 并发库（第 19 章常用补充）

| 组件 | 作用与常用 API |
|---|---|
| `thread` | 启动线程：`std::thread t(fn, args...)`；用 `join()` 等待或 `detach()` 分离 |
| `mutex` | 互斥访问：`lock()`、`unlock()`；优先用 `lock_guard`/`unique_lock` 管理释放 |
| `lock_guard` | 构造时加锁、析构时解锁，适合整个作用域 |
| `unique_lock` | 可延迟/手动加解锁，配合条件变量 |
| `condition_variable` | `wait(lock, predicate)` 等待条件，`notify_one/all()` 唤醒 |
| `atomic<T>` | 无锁（不保证）原子读写；`load`、`store`、`fetch_add`、`compare_exchange_*` |
| `future` / `promise` | 跨线程传递结果；`future::get()` 取得值或重新抛出异常 |
| `async` | `std::async(std::launch::async, fn)` 异步执行并返回 `future` |

```cpp
#include <future>

int main() {
    auto result = std::async(std::launch::async, [] { return 6 * 7; });
    // get() 等待任务结束；同一个 future 只能 get 一次
    return result.get() == 42 ? 0 : 1;
}
```

线程函数访问共享状态时必须同步；`join`/`detach` 前要保证线程对象仍可用，否则析构会调用 `std::terminate`。

```cpp
#include <random>
#include <regex>

std::string mask_digits(const std::string &s) {
    return std::regex_replace(s, std::regex(R"(\d)"), "*");
}

int dice() {
    static std::mt19937 engine{std::random_device{}()};
    static std::uniform_int_distribution<int> dist(1, 6);
    return dist(engine);
}
```

## 第 18 章 用于大型程序的工具

- 异常层次：标准异常在 `<stdexcept>`，包括 `runtime_error`、`logic_error` 及派生类；按 `const&` 捕获。
- 命名空间避免名字冲突；匿名命名空间限制内部链接。头文件用 include guard 或 `#pragma once`。
- 多重继承可能有二义性；虚继承用于共享公共基类子对象。
- `noexcept` 声明函数不抛异常；移动构造标为 `noexcept` 可让容器在扩容时优先移动。
- `extern` 声明跨翻译单元实体；ODR 要求实体定义规则统一。

## 第 19 章 特殊用途语言设施

- `enum class`/`enum struct` 是有作用域枚举，不能隐式转换为整数；底层类型可指定。
- 类成员指针：`int T::*`；成员函数指针需包含参数和 `const` 限定，调用可用 `.*`/`->*`。
- `volatile` 只表示对象可能被外部因素改变，不提供线程同步；并发请使用 `<atomic>` 和线程库（C++11）。
- `alignof(T)` 查询对齐，`alignas(N)` 指定对象/成员对齐。
- `std::move`、`std::forward`、`std::declval` 位于 `<utility>`；`std::is_nothrow_move_constructible` 可查询移动异常保证。

```cpp
enum class Color : unsigned char { red, green, blue };

struct Packet { alignas(16) char bytes[16]; };
static_assert(alignof(Packet) >= 16, "alignment required");
```

### 易错点

- `noexcept` 不是“吞掉异常”；若异常逃出 `noexcept` 函数会调用 `std::terminate`。
- `volatile` 不能替代 `std::atomic`。
- 正则表达式原始字符串 `R"(...)"` 只是减少转义，不改变正则语义。
