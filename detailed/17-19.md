# 《C++ Primer》第 5 版详细总结：第 17-19 章

## 第 17 章 标准库特殊设施

### `tuple` 与 `bitset`

`tuple<Ts...>` 保存不同类型的固定数量值。`get<I>` 按索引访问，`get<T>` 在类型唯一时按类型访问，`tie` 绑定已有变量，`make_tuple` 自动推导类型。

```cpp
std::tuple<std::string, int, double> record{"Ada", 36, 95.5};
auto name = std::get<0>(record);
std::tie(name, std::ignore, std::ignore) = std::make_tuple(std::string{"Bob"}, 20, 88.0);
```

`bitset<N>` 保存固定 N 个二进制位：`set` 置位，`reset` 清位，`flip` 翻转，`test` 检查，`count` 统计，`to_ulong` 转整数。

```cpp
std::bitset<8> flags(0b00010100);
flags.set(7).reset(2);
if (flags.test(7)) std::cout << flags.count();
```

### 正则表达式

`regex_match` 要求整个序列匹配，`regex_search` 查找子串，`regex_replace` 替换匹配；`smatch` 保存字符串结果。模式错误抛 `regex_error`。

```cpp
std::regex email(R"((\w+)@(\w+\.\w+))");
std::smatch match;
if (std::regex_match("a@example.com", match, email))
    std::cout << match[1] << " at " << match[2];
```

### 随机数与时间

随机数库将引擎和分布分离：引擎产生伪随机位，分布转换为目标概率。固定种子可复现实验；`mt19937` 不适合密码。

```cpp
std::mt19937 engine{std::random_device{}()};
std::uniform_int_distribution<int> die(1, 6);
int roll = die(engine);
```

`chrono::duration` 表示间隔，`time_point` 表示时刻；测耗时使用不会回拨的 `steady_clock`：

```cpp
auto start = std::chrono::steady_clock::now();
do_work();
auto elapsed = std::chrono::duration_cast<std::chrono::microseconds>(
    std::chrono::steady_clock::now() - start);
std::cout << elapsed.count();
```

### 其他设施

`numeric_limits<T>` 查询类型范围；`error_code` 携带错误类别和值；`system_error` 可将其包装成异常。底层 API 可用 error_code 重载避免异常穿透。

## 第 18 章 用于大型程序的工具

### 异常安全

标准异常包括 `logic_error` 与 `runtime_error` 及其派生类。按 `const std::exception&` 捕获可统一调用 `what()`。基本保证要求无泄漏且对象有效；强保证要求失败时状态不变；不抛保证要求操作绝不抛。

```cpp
try {
    update_database();
} catch (const std::exception &ex) {
    log(ex.what());
    throw; // 保留原始异常类型
}
```

不要写 `throw ex` 重新抛出捕获对象，这可能按静态类型切片；使用裸 `throw;`。

### `noexcept`

`noexcept` 表示异常不应离开函数；若逃出则调用 `std::terminate`。移动构造和 `swap` 若确实不抛应标注它，容器才能优先移动。

```cpp
static_assert(noexcept(std::declval<std::vector<int>&>().clear()), "clear");
```

`noexcept(expr)` 在编译期查询表达式是否不抛。

### 命名空间、链接与 RTTI

命名空间避免名字冲突；匿名命名空间中的名字具有内部链接。头文件用 include guard 或 `#pragma once`。`extern` 声明其他翻译单元定义的实体；ODR 要求一个实体的定义满足规则。

`typeid` 获取 `type_info`；`dynamic_cast` 沿多态继承层次安全转换，指针失败返回空，引用失败抛 `bad_cast`。频繁依赖 dynamic_cast 通常说明接口缺少虚函数。

### 多重继承

多重继承适合多个独立接口，但同名成员会二义；菱形继承使用虚继承共享公共基类子对象。构造顺序和析构顺序仍分别遵循基类、成员、函数体及其逆序。

## 第 19 章 特殊用途设施

### 作用域枚举

`enum class` 的枚举项位于自己的作用域，不隐式转整数，可以指定底层类型控制大小。

```cpp
enum class Permission : unsigned char { read = 1, write = 2, execute = 4 };
Permission p = Permission::read;
int numeric = static_cast<int>(p);
```

### 成员指针

成员指针保存成员相对于对象的访问方式，而不是普通地址；数据成员用 `obj.*pm` 或 `ptr->*pm` 访问。成员函数指针可用 `std::mem_fn` 或 C++17 `std::invoke` 适配。

```cpp
struct Item { int price; } item{10};
int Item::*member = &Item::price;
std::cout << item.*member;
```

### 对齐、`volatile` 与原子

`alignof(T)` 查询对齐，`alignas(N)` 指定最小对齐；只在 SIMD、硬件缓冲等确有需要时使用。`volatile` 不提供原子性和线程同步。

```cpp
struct alignas(64) Counter {
    std::atomic<long> value{0};
};
static_assert(alignof(Counter) >= 64, "alignment");
```

`atomic<T>` 提供无数据竞争的 `load/store/fetch_add/compare_exchange`。默认 `seq_cst` 最易理解，性能敏感场景才使用 acquire/release/relaxed。

`thread` 启动线程，析构前必须 `join` 或 `detach`；`mutex` 配合 `lock_guard` 自动解锁；`condition_variable::wait(lock,predicate)` 用谓词抵御虚假唤醒；`future/promise/async` 传递结果和异常。

### C++11/17 补充

- `std::byte`（C++17）表达原始字节，不参与整数运算，使用 `to_integer` 转换。
- `std::uncaught_exceptions`（C++17）返回当前未处理异常数量。
- `std::align_val_t`（C++17）支持过度对齐分配。
