# 《C++ Primer》第 5 版详细总结：第 1-6 章

本文不是关键词清单，而是对 C++11 基础语义的解释。示例默认使用 `-std=c++11 -Wall -Wextra -pedantic`。

## 第 1 章 开始

### 程序、编译与 `main`

源文件只是文本。编译器先检查类型和语法并生成目标文件，链接器再把目标文件与标准库、其他源文件的定义组合为可执行程序。只声明而没有定义的函数通常能通过编译，却会在链接时报 `undefined reference`。

```cpp
int add(int, int);                 // 声明：说明接口
int add(int a, int b) { return a + b; } // 定义：提供实现

int main() {
    return add(1, 2) == 3 ? 0 : 1;
}
```

`main` 返回 `int`，0 表示成功。到达 `main` 末尾等价于 `return 0;`，其他返回类型或省略返回类型都不符合标准。

### 标准输入输出

流把程序和设备隔离。`ostream` 接收值并格式化为字符，`istream` 从字符中解析值。`operator<<`/`operator>>` 返回流自身，因此能够链式调用。

```cpp
int sum_from_input(std::istream &in) {
    int sum = 0;
    for (int value = 0; in >> value; )
        sum += value;
    return sum;
}
```

`in >> value` 先读取，再把流转换为布尔状态。遇到 EOF、类型不匹配或设备错误时条件为假。若要从格式错误中恢复：

```cpp
in.clear(); // 清除 failbit
in.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
```

| 对象/函数 | 做什么 | 何时使用 |
|---|---|---|
| `cin` | 标准输入 | 交互或管道输入 |
| `cout` | 普通输出 | 程序正常结果 |
| `cerr` | 诊断输出，通常立即刷新 | 错误信息 |
| `clog` | 缓冲诊断输出 | 日志 |
| `endl` | 换行并刷新 | 必须立即显示时；普通换行用 `\n` |

## 第 2 章 变量和基本类型

### 基本类型与可移植性

整数类型的大小由实现决定，标准只规定最小范围和相对关系。`int` 通常用于普通整数；确需固定位数、序列化或协议字段时使用 `<cstdint>` 的 `int32_t`、`uint64_t`。`char` 是否有符号由实现决定，处理原始字节或传给 `<cctype>` 时先转 `unsigned char`。

无符号算术按模 `2^N` 回绕；有符号溢出是未定义行为。混合运算会把负数转换成很大的无符号数：

```cpp
std::vector<int> v;
// 错误：v.size() - 1 在空 vector 上下溢
for (std::size_t i = 0; i < v.size(); ++i) { /*...*/ }
```

### 初始化不是赋值

初始化在对象诞生时确定初值；赋值替换已经存在的值。C++11 列表初始化 `{}` 统一了语法，并禁止窄化：

```cpp
int a = 3;      // 拷贝初始化
int b(3);       // 直接初始化
int c{3};       // 列表直接初始化
int d = {3};    // 列表拷贝初始化
// int bad{3.14}; // 错误：double 到 int 会丢信息
```

局部内置类型若没有初始化，其值不确定，读取它是未定义行为。类类型是否有默认值由构造函数决定。

### 声明、定义与作用域

声明让名字可见；定义创建实体。`extern int count;` 通常只声明，`int count = 0;` 是定义。一个作用域内的内层名字会隐藏外层同名对象，可以用 `::name` 访问全局名字，但应避免依赖隐藏。

### 引用与指针

引用是已有对象的别名，必须初始化，绑定后不能改绑。指针本身是对象，可以为空、改指向或比较。

```cpp
int value = 10;
int &ref = value;       // 修改 ref 就是修改 value
int *ptr = &value;
int *none = nullptr;    // C++11 类型安全空指针
```

`const int *p` 表示不能通过 p 修改所指整数；`int *const p` 表示 p 自身不能改指向。前者是底层 const，后者是顶层 const。

### `const`、常量表达式与 `constexpr`

`const` 只保证不能通过当前接口修改，不保证值能在编译期获得。`constexpr` 要求初始化器是常量表达式，并使对象成为顶层 const。

```cpp
constexpr int square(int n) { return n * n; }
constexpr int side = 4;
int matrix[square(side)]{}; // 编译期大小
```

C++11 `constexpr` 函数体限制严格，通常只有一条 `return`；C++14 才显著放宽。

### 类型别名、`auto` 与 `decltype`

`using Index = std::vector<int>::size_type;` 给复杂类型命名。`auto` 从初始化器推导类型，通常丢弃引用和顶层 const；需要保留时显式写 `const auto&`。

`decltype(expr)` 不执行表达式，只推导类型：名字得到声明类型；加括号的左值表达式得到引用。

```cpp
const int n = 4;
auto x = n;           // int
const auto &y = n;    // const int&
decltype(n) z = 5;    // const int
decltype((x)) alias = x; // int&
```

### 自定义数据结构

`struct` 默认公有，适合数据聚合；`class` 默认私有，适合维护不变量。头文件应使用 include guard，且不要在头文件写 `using namespace std;`。

## 第 3 章 字符串、向量和数组

### `std::string` 是什么

`string` 是拥有字符存储的可变长容器，自动管理容量并保证字符连续。它解决 C 字符串长度、拷贝、释放和结尾空字符容易出错的问题。

```cpp
std::string describe(std::string name, int age) {
    if (name.empty()) name = "unknown";
    return name + " age=" + std::to_string(age);
}
```

| API | 含义 | 注意 |
|---|---|---|
| `size()/length()` | 字符数 | 返回无符号 `size_type` |
| `empty()` | 是否为空 | 比 `size()==0` 更直接 |
| `operator[]` | 不检查下标 | 越界是未定义行为 |
| `at(i)` | 检查下标 | 越界抛 `out_of_range` |
| `append`, `+=`, `+` | 追加/拼接 | `+` 产生新字符串 |
| `substr(pos,n)` | 返回子串副本 | `pos` 越界抛异常 |
| `find(x,pos)` | 查找 | 失败返回 `string::npos` |
| `insert/erase/replace` | 修改字符区间 | 可能使迭代器失效 |
| `c_str()/data()` | 连续字符指针 | C++11 `data()` 返回只读指针 |
| `getline(in,s)` | 读一整行 | 丢弃分隔换行符 |

### 字符分类

`<cctype>` 的 `isdigit`、`isspace`、`tolower` 等只接受 EOF 或可表示为 `unsigned char` 的值。安全包装：

```cpp
char lower(char ch) {
    auto u = static_cast<unsigned char>(ch);
    return static_cast<char>(std::tolower(u));
}
```

### `std::vector` 是什么

`vector<T>` 是连续存储、动态扩容的同类型序列。随机访问 O(1)，尾部追加摊销 O(1)，中间插入/删除 O(n)。它应是默认序列容器，除非有明确需求选择其他结构。

```cpp
std::vector<int> read_all(std::istream &in) {
    std::vector<int> result;
    for (int x; in >> x; ) result.push_back(x);
    return result; // 移动或返回值优化
}
```

构造方式容易混淆：`vector<int> a(10, 1)` 是十个 1；`vector<int> b{10, 1}` 是两个元素 10 和 1。`reserve(n)` 只预留容量，不能下标访问新增位置；`resize(n)` 真正改变元素数。

扩容后所有指针、引用和迭代器失效；未扩容插入时，插入点及其后通常失效。遍历期间不要随意 `push_back`。

### 迭代器与范围 `for`

迭代器是容器与算法之间的通用游标。`begin()` 指首元素，`end()` 指尾后位置；尾后迭代器只能比较，不能解引用。

```cpp
void double_all(std::vector<int> &v) {
    for (auto &x : v) x *= 2;       // 引用才能修改元素
}

int sum(const std::vector<int> &v) {
    int total = 0;
    for (auto it = v.cbegin(); it != v.cend(); ++it) total += *it;
    return total;
}
```

### 内置数组

数组大小固定、元素连续，不能直接拷贝或赋值。在多数表达式中退化为首元素指针，因此函数参数 `int a[]` 实际是 `int*`，长度必须另传。优先使用 `std::array` 或 `vector`。

```cpp
int a[3]{1, 2, 3};
for (int *p = std::begin(a); p != std::end(a); ++p) { /*...*/ }
```

多维数组是数组的数组；遍历外层必须用引用防止子数组退化：`for (auto &row : matrix)`。

## 第 4 章 表达式

### 值类别与求值

左值通常有稳定身份、可取地址；纯右值通常是计算结果或临时对象；将亡值表示可被移动的对象。值类别影响引用绑定、重载选择和移动语义。

优先级只决定表达式如何分组，不保证操作数求值顺序。C++11 中 `i = i++ + 1` 等对同一标量的无序读写会导致未定义行为。写成多条语句最清晰。

### 算术、逻辑与位运算

`&&` 和 `||` 短路求值，常用于先检查指针再解引用：`p && p->valid()`。位运算针对无符号整数更可预测：`&` 清/测试位，`|` 设置位，`^` 翻转位，`<<`/`>>` 移位。

### 赋值、条件和递增

赋值返回左侧对象，可链式赋值。前置 `++i` 返回递增后的左值；后置 `i++` 保存旧值，迭代器循环中不需要旧值时优先前置形式。

### 类型转换

- `static_cast<T>`：明确的数值转换、相关指针转换。
- `const_cast<T>`：增加或移除底层 const；修改本来就是 const 的对象仍是未定义行为。
- `dynamic_cast<T>`：多态继承层次的运行时安全转换。
- `reinterpret_cast<T>`：低层位模式/指针解释，强依赖平台，应极少使用。

避免 C 风格强制转换，因为它隐藏具体转换类别。

### `sizeof` 与 `typeid`

`sizeof` 通常不求值表达式，返回 `size_t`；数组得到整个数组字节数，指针只得到指针本身大小。`typeid` 在多态对象上可获得动态类型，其他情况多为静态类型。

## 第 5 章 语句

### 条件、循环和作用域

用花括号明确控制范围，即使当前只有一条语句。`switch` 适合离散整型/枚举选择；case 标签必须是常量表达式，贯穿必须是有意行为。

```cpp
std::string grade(char level) {
    switch (level) {
    case 'A': return "excellent";
    case 'B': return "good";
    default:  return "unknown";
    }
}
```

范围 `for` 等价于取得 begin/end 后循环；循环期间改变容器边界可能使隐藏的迭代器失效。

### 异常处理

`throw` 报告当前层无法处理的错误；栈展开会析构已构造的局部对象，这正是 RAII 能自动释放资源的基础。按值抛出、按 `const&` 捕获以保留多态并避免复制。

```cpp
double divide(double a, double b) {
    if (b == 0) throw std::invalid_argument("division by zero");
    return a / b;
}
```

异常适合异常路径，不用于普通分支。捕获应从最具体派生异常到基类 `std::exception` 排列。

## 第 6 章 函数

### 参数传递设计

按值参数获得副本，适合小对象或函数要取得所有权；`const T&` 避免复制并只读；`T&` 表示明确修改调用者；指针通常表达“可能为空”或数组/底层接口。

```cpp
void append_suffix(std::string &text, const std::string &suffix) {
    text += suffix;
}

std::size_t count_char(const std::string &text, char target) {
    return static_cast<std::size_t>(std::count(text.begin(), text.end(), target));
}
```

数组参数会退化，使用迭代器区间、数组引用模板或 `std::array` 才能保留长度。

### 返回值与生命周期

绝不能返回局部变量的引用或指针。按值返回局部对象通常由复制消除或移动优化。返回引用适用于对象生命周期由调用者或更长作用域管理的场景，如容器下标。

### 重载与默认实参

重载不能只靠返回类型区分。编译器先找可行函数，再按转换质量选择最佳匹配；整型提升优于普通数值转换。默认实参从右侧连续提供，只在调用点代入，不属于函数类型。

### `inline`、`constexpr` 与断言

`inline` 主要允许同一定义出现在多个翻译单元，并不强制优化。模板和 inline 函数定义通常放头文件。`assert(expr)` 是调试期检查，定义 `NDEBUG` 后消失，不能用于必须执行的业务逻辑。

### 函数指针与 `initializer_list`

函数指针保存具有特定签名的函数地址。`initializer_list<T>` 是只读、轻量的同类型值序列，适合数量可变但类型相同的参数。

```cpp
int sum(std::initializer_list<int> values) {
    return std::accumulate(values.begin(), values.end(), 0);
}

int (*operation)(int, int) = add;
```

尾置返回类型 `auto f(...) -> T` 适合返回类型依赖参数的模板；真正的完美转发和可变参数模板在第 16 章展开。
